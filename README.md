# BLOODWORLD RPG v0.3.0

## GitHubの現在のフラット配置に対応
このバージョンは、すべてのファイルをリポジトリ直下に置く構成です。フォルダ作成は不要です。

リポジトリ直下に次の6ファイルを置いてください。
- `index.html`
- `style.css`
- `game.js`
- `game-data.js`
- `README.md`

ZIPを解凍し、5ファイル（READMEを含む）を既存リポジトリで上書きしてCommitします。GitHub Pagesは `main` / `/(root)` のままです。

## v0.3.0の主な変更
- マップの通路・建物・瓦礫・街灯の視認性を強化
- 黄色い立体マーカー、点滅リング、目的地ラベル、黄色いルート線を追加
- 飢京の4エリア（中央街区、廃棄住宅街、地下交通網、旧行政区）を実装
- 「MAP / 移動」から解放済みエリアへ移動
- NPCと目的地イベントを各エリアに配置し、調査バトル勝利で次エリアを解放
- 敵の種類とエリアごとの出現構成を追加
- スキル開発時のSPコストと使用時のMPコストを別計算
- 威力、全体攻撃、属性、追加効果に応じてSP/MPコストが上昇
- スキルを一覧から装備変更可能。戦闘中のMP不足をチェック
- 回復、防御、強化、弱体化、状態異常カテゴリの基本処理を追加
- アイテム使用と戦闘中のアイテム使用に対応
- セーブデータにエリア解放・イベント進行・スキル情報を保存

## 操作
- PC：WASD / 矢印キーで移動、Space / Enterで調べる
- スマホ：画面下の方向ボタン、「調べる」
- `MAP / 移動`：解放済みエリアへ移動
- `SKILLS`：戦闘で使うスキルを選んで装備
- `DEVELOP`：SPを消費してスキルを開発
- `ITEMS`：HP/MP回復アイテムを使用
- `SAVE`：ブラウザ保存・JSON書き出し

## 進行
1. 中央街区で黄色いマーカーの避難民に話しかける。
2. 黄色いルート線に沿って目的地マーカーまで移動し、調べる。
3. 発生する調査戦闘に勝利すると廃棄住宅街が解放される。
4. MAP / 移動から次のエリアへ進み、同様に調査を進める。
5. 飢京の4エリアを順番に解放する。

## スキルコスト
- 開発SP：威力、対象範囲、追加効果、属性、カテゴリに応じて増加。
- 使用MP：威力、対象範囲、追加効果、属性、カテゴリに応じて増加。
- MP消費量は自動計算で、0には設定できません。開発画面にSP/MPの必要量がリアルタイム表示されます。
- 強力な技はMP消費が大きく、連続使用にはMP回復アイテムが必要です。
