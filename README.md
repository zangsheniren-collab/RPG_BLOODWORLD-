# BLOODWORLD RPG v0.2.0

## GitHub Pagesへの配置
1. ZIPを解凍します。
2. GitHubでリポジトリを開き、`index.html`、`css`、`js`、`data`、`assets`をリポジトリ直下へアップロードします。
3. Settings → Pages → Deploy from a branch を選択。
4. Branch: `main`、Folder: `/(root)` を選択してSave。
5. 公開URLを開き、キャッシュが残る場合は再読み込みしてください。

## v0.2.0の改善
- 飢京らしい廃墟・建物・街灯・瓦礫・看板を描くマップに刷新
- 次の目的地を金色の発光マーカーと目的カードで強調
- 複数種類の敵（路地の異形、這いずる屍獣、赤霧の浮遊体、廃材喰らい、擬態する影）
- スキル一覧から使用スキルを選択・装備できるよう修正
- アイテム一覧から応急薬・簡易補助剤を使用可能
- 戦闘中にもアイテムを使用可能
- スキル開発後に自動装備
- モバイル操作と画面レイアウト改善
- データ定義を `data/game-data.js` に分離

## 操作
- PC: WASD / 矢印キーで移動、Space / Enterで調べる
- スマホ: 画面内の方向ボタン、「調べる」ボタン
- SKILLS: スキルを装備
- ITEMS: アイテムを使用
- DEVELOP: スキルポイントを使って技を作成
- SAVE: ブラウザ保存・JSONバックアップ

## 注意
このバージョンは飢京・中央街区の試作版です。12エリア全体、仲間、クエスト分岐、属性別の実際の追加効果、歩行アニメーションなどは今後の開発対象です。旧版 v0.1.0 のセーブは一部項目の互換性が保証されません。更新前に旧版からJSONを書き出して保管してください。
